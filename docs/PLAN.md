# План автоматизации LMS Synergy

## Анализ текущей ситуации

### Структура авторизации:
- URL: `https://lms.synergy.ru/`
- Форма авторизации:
  - Поле логина: `popupUsername` (Логин / Email)
  - Поле пароля: `popupPassword`
  - Кнопка входа: `popupLoginBtn` (ссылка с классом "button button-big")
  - Action: `https://lms.synergy.ru/user/login` (POST)
