# Исправление ошибки базы данных

## Проблема
Ошибка SQLAlchemy: `sqlite3.OperationalError: no such column: semesters.number`

## Причина
В модели `Semester` в файле `models.py` было добавлено поле `number` (строка 18), но база данных была создана до этого изменения и не содержала данную колонку.

## Решение
1. **Добавлена недостающая колонка в базу данных:**
   ```sql
   ALTER TABLE semesters ADD COLUMN number INTEGER;
   ```

2. **Создан скрипт миграции** `migrate_db.py` для автоматического обновления структуры базы данных в будущем.

## Проверка
- ✅ Колонка `number` добавлена в таблицу `semesters`
- ✅ Запросы к модели `Semester` работают без ошибок
- ✅ API endpoint `/api/semesters` функционирует корректно
- ✅ Скрипт миграции протестирован

## Использование скрипта миграции
```bash
# Применить миграции
python migrate_db.py

# Показать текущую схему базы данных
python migrate_db.py schema
```
