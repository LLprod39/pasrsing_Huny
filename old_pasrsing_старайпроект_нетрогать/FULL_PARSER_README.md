# Полный парсер Synergy LMS

## Что было сделано

### ✅ Создан полный парсер (`full_parser.py`)
- **Парсит все данные за один раз**: семестры, курсы и материалы
- **Детальная информация о материалах**:
  - Названия материалов
  - Типы (video, pdf, section, material)
  - Статус блокировки (`is_blocked`)
  - Прогресс просмотра (`progress`)
  - Статус завершения (`completion_status`)
  - Длительность видео (`duration_seconds`)
  - Уровень вложенности (`level`)
  - Data-index для идентификации

## Как использовать

### 1. Через веб-интерфейс
1. Откройте http://localhost:5000
2. Нажмите кнопку "🚀 Полная синхронизация"
3. Дождитесь завершения (может занять несколько минут)
4. Все данные будут загружены в базу данных

### 2. Через командную строку
```bash
python full_parser.py
```
Результат сохранится в JSON файл с временной меткой.

### 3. Через API
```bash
curl -X POST http://localhost:5000/api/sync-all
```

## Структура данных

### Семестр
```json
{
  "name": "Семестр 1",
  "url": "https://lms.synergy.ru/student/up/",
  "number": 1,
  "status": "active",
  "courses": [...]
}
```

### Курс
```json
{
  "name": "История России",
  "url": "https://lms.synergy.ru/lntools/versiongroupassign/contents/student/26725867",
  "control_type": "экзамен",
  "status": "open",
  "materials_count": 70,
  "materials": [...]
}
```

### Материал
```json
{
  "name": "Лекция 1. Введение в историю",
  "url": "https://lms.synergy.ru/...",
  "type": "video",
  "is_blocked": false,
  "progress": "50%",
  "completion_status": "in_progress",
  "duration_seconds": 1800,
  "level": 0,
  "data_index": "123"
}
```
