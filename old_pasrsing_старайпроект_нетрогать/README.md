# Synergy LMS Automation & Parsing Tool

Этот проект представляет собой комплексное решение для автоматизации работы с LMS Synergy. Он включает в себя веб-интерфейс для управления процессом, парсер для сбора данных (семестры, курсы, материалы) и сервис автоматизации для прохождения материалов (просмотр видео, подтверждение изучения).

## Основные возможности

*   **Веб-интерфейс (Flask)**: Удобная панель управления для просмотра курсов, запуска синхронизации и задач автоматизации.
*   **Парсинг данных**:
    *   Автоматический сбор информации о семестрах, курсах и учебных материалах.
    *   Поддержка вложенных структур материалов.
    *   Определение типов материалов (видео, PDF, тесты).
*   **Автоматизация обучения**:
    *   **Авто-просмотр видео**: Эмуляция просмотра видео (фоновое воспроизведение с учетом длительности).
    *   **Авто-подтверждение**: Автоматическое нажатие кнопок подтверждения изучения материала.
    *   **Полное прохождение курса**: Возможность запустить автоматическое прохождение всех видео-материалов курса одной кнопкой.
*   **База данных**: Хранение всей информации в локальной базе данных SQLite.

## Установка

1.  **Клонируйте репозиторий** (или распакуйте архив).
2.  **Установите зависимости**:
    ```bash
    pip install -r requirements.txt
    ```
    *Примечание: Если `requirements.txt` отсутствует, основные зависимости: `flask`, `flask-sqlalchemy`, `flask-cors`, `selenium`, `webdriver-manager`, `beautifulsoup4`, `requests`.*

3.  **Настройка драйвера**:
    Проект использует Selenium. Драйвер Chrome (`chromedriver`) должен установиться автоматически с помощью `webdriver-manager` или Selenium Manager. Убедитесь, что у вас установлен браузер Google Chrome.

## Конфигурация

Основные настройки находятся в файле `config.py` (если он есть) или задаются в `app.py`.
Учетные данные для входа в LMS можно передавать через веб-интерфейс или настроить в коде (например, в `parser.py` для автономного режима).

## Использование

### 1. Запуск Веб-приложения (Рекомендуется)

Это основной способ взаимодействия с системой.

```bash
python app.py
```

После запуска откройте браузер и перейдите по адресу: `http://localhost:5000`

**Возможности в веб-интерфейсе:**
*   Просмотр списка семестров и курсов.
*   Синхронизация данных с LMS (кнопки "Sync").
*   Запуск автоматического просмотра видео для конкретного материала.
*   Запуск полного прохождения курса (авто-просмотр всех видео).

### 2. Запуск автономного парсера

Для использования скрипта без веб-интерфейса (через консоль):

```bash
python parser.py
```

Следуйте инструкциям в консоли:
1.  Выберите семестр.
2.  Выберите курс.
3.  Выберите материалы для обработки (просмотр/подтверждение).

### 3. Альтернативный веб-интерфейс (WebSocket)

Существует альтернативная версия с поддержкой WebSocket для отображения прогресса в реальном времени:

```bash
python web_app.py
```

## Структура проекта

### Основные компоненты

*   **`app.py`**: Главный файл веб-приложения (Flask). Содержит API endpoints и логику работы с базой данных.
*   **`parser_service.py`**: Сервисный слой, отвечающий за взаимодействие с Selenium для парсинга данных (семестры, курсы, материалы).
*   **`automation_service.py`**: Сервис для выполнения фоновых задач автоматизации (просмотр видео, подтверждение). Управляет потоками и статусами задач.
*   **`parser.py`**: Автономный скрипт парсера (консольная версия). Содержит прямую логику работы с Selenium.
*   **`models.py`**: Описание моделей базы данных (SQLAlchemy): `Semester`, `Course`, `Material`, `AutomationTask`.

### Вспомогательные файлы

*   **`full_parser.py`**: Расширенная логика парсинга (используется сервисами).
*   **`config.py`**: Файл конфигурации.
*   **`web_app.py`**: Альтернативный сервер с WebSocket.
*   **`requirements.txt`**: Список зависимостей Python.

## База данных

Проект использует SQLite (`synergy_lms.db`). Основные таблицы:

*   **semesters**: Семестры (номер, название, статус).
*   **courses**: Курсы (привязаны к семестру, содержат статус, прогресс).
*   **materials**: Материалы курса (видео, PDF, тесты). Содержат ссылки, статус выполнения, длительность.
*   **automation_tasks**: Задачи автоматизации (история и текущий статус фоновых процессов).

## Решение проблем

*   **Ошибка драйвера Chrome**: Если возникает ошибка при запуске Selenium, убедитесь, что версия Chrome соответствует версии драйвера. Проект пытается автоматически скачать нужный драйвер.
*   **Ошибка авторизации**: Проверьте логин и пароль. Если сайт LMS обновил дизайн страницы входа, возможно, потребуется обновить селекторы в методе `login` (`parser_service.py` или `parser.py`).
*   **Элементы не найдены (TimeoutException)**: Возможно, страница загружается медленно или изменилась верстка. Попробуйте увеличить таймауты в коде (`WebDriverWait`).
