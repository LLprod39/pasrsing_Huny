# 🚀 Быстрый старт

База данных была пересоздана с новой структурой. Теперь можно запускать приложение!

## Запуск

```bash
python app.py
```

## Первое использование

1. Откройте браузер: **http://localhost:5000**

2. Нажмите **"🔄 Синхронизировать семестры"**
   - Браузер откроется автоматически
   - Произойдёт вход в систему
   - Семестры загрузятся из учебного плана `/student/up/`

3. Выберите **семестр** из списка слева

4. Нажмите **"🔄 Синхронизировать курсы"**
   - Загрузятся курсы выбранного семестра

5. Кликните на **курс** для просмотра материалов

6. Нажмите **"🔄 Синхронизировать материалы"**
   - Загрузятся материалы курса

7. Используйте кнопки автоматизации:
   - **"▶ Просмотреть"** - запустить просмотр видео
   - **"✓ Подтвердить"** - подтвердить материал
   - **"▶ Автоматически пройти курс"** - пройти весь курс

## Структура данных

Теперь данные парсятся из учебного плана:

- **Семестры**: `tbody.semester.s1`, `s2`, etc.
- **Курсы**: `tr.discipl` внутри соответствующего семестра
- **Материалы**: `ul.sidebar` на странице курса

Все данные кэшируются в SQLite и обновляются только при ручной синхронизации.

## Если что-то не работает

1. **Обновите Selenium**:
   ```bash
   pip install --upgrade selenium
   ```

2. **Обновите Chrome** до последней версии

3. **Проверьте учётные данные** в `config.py`

4. **Посмотрите логи**:
   - Консоль Flask (где запущен `python app.py`)
   - Файл `synergy_parser.log`
