# Исправления парсинга - ошибка 404

## Проблема
При попытке синхронизации семестров возникала ошибка 404 для URL `https://lms.synergy.ru/student/my-courses`

## Причина
В веб-приложении использовался неправильный URL. Оригинальный парсер использует **`/student/up/`** (учебный план), а не `/student/my-courses`.

## Исправления

### 1. Изменена структура парсинга

**Старый подход** (неправильный):
- URL: `/student/my-courses`
- Искал: `.semester-item`, `.tab-pane`, `.course-card`

**Новый подход** (правильный):
- URL: `/student/up/` (страница учебного плана)
- Семестры: `tbody.semester.s1`, `tbody.semester.s2`, etc.
- Курсы: `tr.discipl` внутри соответствующего `tbody`

### 2. Обновлена модель Semester

Добавлено поле `number` для хранения номера семестра:

```python
class Semester(db.Model):
    number = db.Column(db.Integer, nullable=False, unique=True)
```

### 3. Переписан parser_service.py

#### fetch_semesters()
- Переход на `/student/up/`
- Поиск всех `tbody.semester`
- Извлечение номера из класса (`s1`, `s2`, etc.)

#### fetch_courses(semester_number)
- Принимает номер семестра вместо URL
- Ищет конкретный `tbody.semester.s{number}`
- Парсит `tr.discipl` строки с курсами

### 4. Обновлён app.py

- Синхронизация использует `semester.number` вместо URL
- Добавлено поле `number` при создании семестров

## Как применить исправления

### 1. Сброс базы данных

Структура БД изменилась, нужно пересоздать:

```bash
python reset_db.py
```

Это:
- Удалит старый `synergy_lms.db`
- Создаст новую БД с полем `number` в таблице semesters

### 2. Перезапуск приложения

```bash
# Остановите текущий процесс (Ctrl+C)
python app.py
```

### 3. Синхронизация данных

1. Откройте http://localhost:5000
2. Нажмите "🔄 Синхронизировать семестры"
3. Теперь должно работать без ошибки 404!

## Структура данных на LMS

### Учебный план (/student/up/)

```html
<tbody class="semester s1">
    <tr class="discipl">
        <td><a href="/student/course/...">Название курса</a></td>
        <td>...</td>
        <td>Экзамен/Зачет</td>
    </tr>
</tbody>

<tbody class="semester s2">
    <tr class="discipl">
        ...
    </tr>
</tbody>
```

### Что извлекается:

**Семестры:**
- Номер: из класса `s1`, `s2`, etc.
- Название: `"Семестр {number}"`
- URL: всегда `/student/up/`

**Курсы:**
- Название: текст ссылки
- URL: href ссылки
- Тип контроля: 3-я колонка (td)
