# 🎓 Synergy LMS Web Automation

Веб-приложение для автоматизации обучения на платформе Synergy LMS с кэшированием данных в базе данных.

## 🚀 Основные возможности

- **Синхронизация семестров и курсов** - автоматическое получение данных из LMS
- **Кэширование в БД** - данные сохраняются локально, повторный парсинг не требуется
- **Интеллектуальное обновление** - синхронизируются только измененные данные
- **Автоматизация просмотра видео** - запуск и ожидание видеоматериалов
- **Подтверждение материалов** - автоматическое подтверждение прохождения
- **Пакетное прохождение курсов** - автоматическое прохождение всех материалов курса
- **Фоновые задачи** - асинхронное выполнение автоматизации
- **Веб-интерфейс** - удобный интерфейс для управления обучением

## 📦 Установка

### 1. Клонирование/подготовка проекта

Убедитесь, что у вас установлен Python 3.7+:

```bash
python --version
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка учетных данных

Откройте файл [config.py](config.py) и измените credentials:

```python
@dataclass
class Credentials:
    username: str = "your_email@mail.ru"  # ВАШ EMAIL
    password: str = "your_password"        # ВАШ ПАРОЛЬ
```

## 🎯 Запуск приложения

### Запуск веб-сервера

```bash
python app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

### Первый запуск

1. Откройте браузер и перейдите на http://localhost:5000
2. Нажмите **"🔄 Синхронизировать семестры"** - это загрузит список семестров из LMS
3. Выберите семестр из списка слева
4. Нажмите **"🔄 Синхронизировать курсы"** - загрузятся курсы выбранного семестра
5. Кликните на курс для просмотра материалов
6. Нажмите **"🔄 Синхронизировать материалы"** - загрузятся материалы курса

## 📖 Использование

### Синхронизация данных

**Семестры:**
- Нажмите "Синхронизировать семестры" в шапке
- Данные загрузятся из LMS и сохранятся в БД
- При повторной синхронизации обновятся только измененные данные

**Курсы:**
- Выберите семестр
- Нажмите "Синхронизировать курсы"
- Курсы сохранятся в БД и будут доступны оффлайн

**Материалы:**
- Откройте курс
- Нажмите "Синхронизировать материалы"
- Материалы загрузятся и сохранятся в БД

### Автоматизация обучения

#### Просмотр видео

1. Откройте курс с видеоматериалами
2. Нажмите **"▶ Просмотреть"** на нужном видео
3. Задача запустится в фоновом режиме
4. Прогресс отображается в панели "Задачи автоматизации" справа
5. После завершения материал автоматически подтверждается

#### Подтверждение материала

1. Нажмите **"✓ Подтвердить"** на материале
2. Задача выполнится в фоне
3. Материал будет отмечен как завершенный

#### Автоматическое прохождение курса

1. Откройте курс
2. Нажмите **"▶ Автоматически пройти курс"**
3. Подтвердите действие
4. Все незаблокированные видеоматериалы будут пройдены автоматически
5. Прогресс отображается в реальном времени

### Панель задач

Справа отображаются активные задачи автоматизации:

- 🟡 **Ожидание** - задача в очереди
- 🔵 **Выполняется** - задача выполняется (с прогресс-баром)
- 🟢 **Завершено** - задача успешно выполнена
- 🔴 **Ошибка** - произошла ошибка (показывается сообщение)

## 🗄️ База данных

### Структура

Приложение использует SQLite база данных (`synergy_lms.db`):

- **semesters** - семестры
- **courses** - курсы
- **materials** - материалы курсов
- **automation_tasks** - задачи автоматизации

### Кэширование

**Преимущества:**
- Быстрый доступ к данным без повторного парсинга
- Работа даже при недоступности LMS
- Экономия трафика и времени
- Отслеживание прогресса

**Обновление данных:**
- Данные обновляются только при ручной синхронизации
- При синхронизации обновляются только измененные записи
- Старые данные не удаляются, а обновляются

## 🔧 Архитектура

### Компоненты

**Backend:**
- [app.py](app.py) - Flask приложение с API endpoints
- [models.py](models.py) - SQLAlchemy модели БД
- [parser_service.py](parser_service.py) - интеграция с парсером
- [automation_service.py](automation_service.py) - фоновые задачи автоматизации
- [config.py](config.py) - конфигурация

**Frontend:**
- [templates/index.html](templates/index.html) - HTML интерфейс
- [static/css/style.css](static/css/style.css) - стили
- [static/js/app.js](static/js/app.js) - JavaScript логика

### API Endpoints

#### Семестры
- `GET /api/semesters` - получить все семестры
- `POST /api/semesters/sync` - синхронизировать семестры
- `GET /api/semesters/{id}` - получить семестр с курсами

#### Курсы
- `GET /api/courses?semester_id={id}` - получить курсы семестра
- `POST /api/semesters/{id}/courses/sync` - синхронизировать курсы
- `GET /api/courses/{id}` - получить курс с материалами
- `POST /api/courses/{id}/sync` - синхронизировать материалы курса

#### Материалы
- `GET /api/materials/{id}` - получить материал
- `PATCH /api/materials/{id}` - обновить материал

#### Автоматизация
- `POST /api/automation/watch-video/{material_id}` - запустить просмотр видео
- `POST /api/automation/confirm-material/{material_id}` - подтвердить материал
- `POST /api/automation/complete-course/{course_id}` - пройти весь курс
- `GET /api/automation/tasks` - получить задачи
- `GET /api/automation/tasks/{id}` - статус задачи
- `POST /api/automation/tasks/{id}/cancel` - отменить задачу

## ⚙️ Конфигурация

### Настройки парсера (config.py)

```python
@dataclass
class ParserConfig:
    base_url: str = "https://lms.synergy.ru"
    timeout: int = 20
    max_workers: int = 5  # Количество потоков для параллельной обработки
    headless_mode: bool = True  # Скрытый режим браузера
```

### Настройки браузера

```python
@dataclass
class BrowserOptions:
    disable_images: bool = False  # Отключить загрузку изображений
    disable_css: bool = False     # Отключить CSS
```

## 🐛 Отладка

### Режим отладки браузера

Чтобы видеть что происходит в браузере:

1. Откройте [config.py](config.py)
2. Установите `HEADLESS_MODE = False`
3. Перезапустите приложение
4. Браузер будет открываться видимым окном

### Логи

Логи сохраняются в `synergy_parser.log`:

```bash
# Просмотр логов в реальном времени
tail -f synergy_parser.log
```

## ⚠️ Важные замечания

### Безопасность

**ВНИМАНИЕ:** Учетные данные хранятся в открытом виде в [config.py](config.py)

**Для production:**
1. Используйте переменные окружения
2. Используйте `.env` файл (добавьте в `.gitignore`)
3. Никогда не коммитьте credentials в Git

### Ограничения

- Автоматизация может нарушать ToS платформы - используйте на свой риск
- Работает только с вашим аккаунтом
- Не обходит CAPTCHA и 2FA
- Требует стабильного интернета для синхронизации

### Производительность

- Первая синхронизация может занять время (зависит от количества курсов)
- Фоновые задачи выполняются параллельно
- Каждая задача использует отдельный браузер

## 🔄 Обновление с старой версии

Если у вас уже есть `parser.py` или `test.py`:

1. Установите новые зависимости: `pip install -r requirements.txt`
2. Запустите `python app.py`
3. База данных создастся автоматически
4. Старые скрипты продолжат работать независимо
